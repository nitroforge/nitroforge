## About

We make **Mario Kart Nitro**, a Mario Kart Wii mod for Dolphin, and the tools around it. Everything here is open source and built for the community.

## Projects

### <img src="assets/i-rocket.svg" width="22" alt="" />&nbsp;&nbsp;[NitroLauncher](https://github.com/nitroforge/NitroLauncher)

The one-click launcher. It installs the mod, keeps it current and starts Dolphin. Includes a Mii editor and a performance mode.

[![Stars](https://img.shields.io/github/stars/nitroforge/NitroLauncher?style=flat-square&color=f0561e&labelColor=161b22)](https://github.com/nitroforge/NitroLauncher/stargazers)
[![Last commit](https://img.shields.io/github/last-commit/nitroforge/NitroLauncher?style=flat-square&color=30363d&labelColor=161b22)](https://github.com/nitroforge/NitroLauncher/commits/main)
[![Download](https://img.shields.io/badge/Download-latest%20release-30363d?style=flat-square&labelColor=161b22)](https://github.com/nitroforge/NitroLauncher/releases/latest)

### <img src="assets/i-package.svg" width="22" alt="" />&nbsp;&nbsp;[Nitropack](https://github.com/nitroforge/Nitropack)

The content pack: tracks, characters, music and more. The launcher syncs it for you, so nobody copies files by hand.

[![Stars](https://img.shields.io/github/stars/nitroforge/Nitropack?style=flat-square&color=f0561e&labelColor=161b22)](https://github.com/nitroforge/Nitropack/stargazers)
